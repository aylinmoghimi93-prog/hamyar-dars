# همیار درس (MVP) — کلاس ششم

اپ تکلیف مدرسه با دو پنل (دانش‌آموز و معلم)، دستیار آموزشی قدم‌به‌قدم و تحلیل کلاس برای معلم.

## اجرا
نیازمندی: فقط Node.js نسخه ۱۸ یا بالاتر (هیچ پکیج اضافه‌ای لازم نیست).

    cd hamyar-dars
    npm start        # یا: node server.js

سپس در مرورگر باز کنید: http://localhost:3000  (پورت دیگر: `PORT=4000 npm start`)

## حساب‌های نمونه
- دانش‌آموز: `zeinab / 1111` ، `sara / 2222` ، `arian / 3333`
- معلم: `karimi / 1234`

برای بازنشانی داده‌های نمونه، فایل `data/db.json` را پاک کنید و سرور را دوباره اجرا کنید.

## ساختار
- `server.js` بک‌اند (ورود، دسترسی‌ها، تکالیف، ثبت زمان، دستیار، تحلیل کلاس)
- `public/` فرانت‌اند فارسی و راست‌چین (`index.html`, `app.js`, `style.css`)
- `data/db.json` دیتابیس فایل JSON (بعد از اولین اجرا ساخته می‌شود)

## حریم خصوصی
- رمزها با scrypt هش می‌شوند و دسترسی‌ها در سرور بررسی می‌شود.
- دانش‌آموز فقط تکالیف و سؤال‌های خودش را می‌بیند.
- معلم فقط دانش‌آموزان کلاس خودش را می‌بیند و متن سؤال‌ها را نمی‌بیند؛ فقط موضوع و تعداد درخواست کمک.
- تشخیص چهره، ضبط مخفی یا نظارت پنهان وجود ندارد. میکروفون فقط با زدن دکمه فعال می‌شود.

## قدم بعدی تا اپ واقعی
1. جایگزین کردن JSON با دیتابیس واقعی (PostgreSQL یا SQLite)
2. وصل کردن مدل هوش مصنوعی به دستیار با دستور «راهنمایی پلکانی، بدون جواب مستقیم» (الان قالب‌های ثابت است)
3. ورود امن‌تر: HTTPS، محدودیت تلاش ورود، ساخت حساب توسط مدیر مدرسه، تغییر رمز
4. چند کلاس و چند معلم، رضایت‌نامه والدین و سیاست نگهداری داده
5. اعلان‌ها، PWA برای موبایل و تست خودکار
